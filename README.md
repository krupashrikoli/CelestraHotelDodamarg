# Celéstra | Premium Hotel in Dodamarg

Standalone property website for **celestra.ghdhotels.in**.

## Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

Point **celestra.ghdhotels.in** at this repository’s production build (`npm run build && npm start` or your host’s Next.js adapter).
